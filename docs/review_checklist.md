# Pull Request Review Checklist

## Reviewer

- [ ] I am not the author of this PR.
- [ ] I understand what the PR is intended to change.
- [ ] The changes are within the scope of the related task/backlog item.
- [ ] The implementation is understandable and maintainable.
- [ ] No unnecessary files or unrelated changes were introduced.
- [ ] No API keys, passwords, tokens, or other secrets are committed.
- [ ] Tests were added or updated where applicable.
- [ ] Existing tests/checks still pass.
- [ ] Documentation was updated where necessary.
- [ ] The PR follows the project's branch and commit conventions.
- [ ] Review comments have been addressed or resolved.

## Decision

- [ ] Approve
- [ ] Request changes
